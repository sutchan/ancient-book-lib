| 用户账号系统 | ❌ 不做 | 与「所有配置本地存储」隐私承诺冲突（需求洞察 X1） |

| 真实 5GB 数据接入 | ✅ 已闭环 | v1.3.0 起改「直连殆知阁 v20 + HTTP Range 分片」，原阻塞消除 |
