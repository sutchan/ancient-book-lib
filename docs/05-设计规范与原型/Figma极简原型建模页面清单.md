# 古籍通 AncientBook｜Figma 极简原型建模页面清单（可直接落地）

**适用用途**：Figma 低保真/高保真原型搭建、页面结构落地、前端一比一还原

**原型设计原则（强制执行）**：极简留白、阅读优先、无装饰元素、结构清晰、层级克制、学术国风素雅，仅做功能布局，不做多余视觉装饰

**统一布局模板**：全站通用「顶部导航 + 主体内容区 + 底部页脚」三段式结构，所有页面严格复用，保证全站一致性

---

## 一、全局通用固定组件（所有页面共用，仅建一次）

全局组件统一封装，页面直接复用，禁止重复设计、差异化样式

- **全局导航栏 Navbar**：品牌Logo（古籍通 AncientBook）、主导航菜单、繁简切换按钮、主题切换按钮（日间/护眼/深色）
- **全局页脚 Footer**：开源声明、数据来源、免责公示、解压密码、网盘备用链接、版权说明
- **搜索组件 Search**：居中搜索输入框、检索类型切换（标题检索/全文检索）、搜索按钮、清空按钮
- **面包屑导航 Breadcrumb**：层级回溯导航（首页-分类-书籍-章节）
- **空状态组件**：无搜索结果、无数据、加载失败统一空页面样式
- **加载状态组件**：极简加载占位、无花哨动效

---

## 二、全站完整页面原型清单（V1.0 全部页面）

共8个核心页面，无隐藏页面、无特殊弹窗页面，全部基于三段式布局搭建

### Page 01：首页（首页门户）

**页面路由**：/

**页面定位**：产品门户、功能聚合、入口分发

**原型模块结构**

1. 全局导航栏（固定置顶）
2. 极简Slogan区域：产品定位文案，无大图、无装饰
3. 全局居中搜索框模块
4. 十大馆藏卡片入口区（均等网格排布）
5. 学术工具快捷入口（人物考据、社会关系溯源）
6. 全局页脚

**交互原型**：卡片hover高亮、点击跳转对应分类页

### Page 02：馆藏分类列表页

**页面路由**：/category/[type]

**页面定位**：一级馆藏分类书籍聚合列表

**原型模块结构**

1. 全局导航栏
2. 面包屑导航（首页 > 对应馆藏）
3. 馆藏分类标题 + 简介文本
4. 书籍极简列表（纯文字列表、hover高亮）
5. 懒加载/分页占位区域
6. 全局页脚

### Page 03：书籍章节目录页

**页面路由**：/book/[id]

**页面定位**：单本古籍卷次、章节、篇目结构化目录

**原型模块结构**

1. 全局导航栏
2. 面包屑导航（首页 > 馆藏 > 书籍）
3. 书籍基础信息（书名、馆藏分类、简介）
4. 三级结构化章节目录列表（卷/篇/章层级缩进）
5. 章节快速跳转、返回顶部按钮
6. 全局页脚

### Page 04：古籍阅读页（核心主页面）

**页面路由**：/read/[chapterId]

**页面定位**：双语古籍沉浸式阅读、核心功能页

**原型模块结构**

1. 全局导航栏
2. 面包屑完整层级导航
3. 章节标题（卷次/篇目名称）
4. 阅读控制面板：繁简切换、主题切换、字号调节、行距调节
5. 古籍正文阅读主体区（大留白、段落规整排布）
6. 划词释义/划词检索弹窗占位（轻量化悬浮、不遮挡正文）
7. 上下章节切换按钮（底部常驻）
8. 阅读进度记忆占位
9. 全局页脚

### Page 05：检索结果页

**页面路由**：/search

**页面定位**：关键词检索结果展示、上下文预览

**原型模块结构**

1. 全局导航栏（保留搜索框可二次检索）
2. 检索信息统计区：检索关键词、命中结果数量
3. 检索筛选简易面板（朝代/馆藏分类筛选）
4. 结果列表单元：出处路径、章节标题、命中高亮片段、上下文预览
5. 结果分页/懒加载区域
6. 全局页脚

### Page 06：人物考据页

**页面路由**：/character

**页面定位**：历史人物档案、生平、宦历、关联史料聚合

**原型模块结构**

1. 全局导航栏
2. 人物搜索框（姓名/字号检索）
3. 人物基础信息卡片（结构化布局：朝代、籍贯、生卒、官职）
4. 生平履历、宦历经历分区模块
5. 该人物关联古籍文献列表模块
6. 重名人物筛选切换模块
7. 全局页脚

### Page 07：社会关系溯源页

**页面路由**：/relation

**页面定位**：历史人物关系查询、双人关联溯源

**原型模块结构**

1. 全局导航栏
2. 双人关系查询表单（人物A/人物B双输入）
3. 单人多维关系展示区：亲属、师生、同僚、交游分区
4. 关系溯源史料出处展示模块
5. 全局页脚

### Page 08：帮助与合规声明页

**页面路由**：/help

**页面定位**：功能教程、开源公示、合规声明、共建说明

**原型模块结构**

1. 全局导航栏
2. 页面标题与说明
3. 功能使用教程分区
4. 开源共建说明分区
5. 合规声明、免责条款、数据来源公示分区
6. 反馈渠道公示
7. 全局页脚

## 三、Figma 原型统一适配规范（必遵）

### 3.1 三端适配尺寸

- **桌面端**：1920px / 1200px 居中容器（最大内容宽1200px）
- **平板端**：768px 自适应布局
- **移动端**：375px 标准移动端尺寸，单列全屏沉浸

### 3.2 原型极简规范（禁止项）

- 禁止装饰性插画、背景图案、花哨动效、立体样式
- 禁止弹窗广告、浮窗、营销组件
- 禁止差异化页面布局，所有页面严格三段式统一
- 禁止高饱和配色，严格遵循项目三套主题色板

### 3.3 组件复用规则

所有全局组件、按钮、输入框、卡片、列表样式统一建组件库，页面仅复用，不单独修改样式，保证前端还原零偏差。
