# 古籍通 AncientBook｜UI/UX 全局视觉与交互设计规范

**文档版本**：V1.0 正式定稿

**文档定位**：项目唯一官方视觉与设计标准，统一全站页面结构、色彩系统、字体系统、组件样式、交互逻辑、适配规则。所有原型、UI设计、前端还原必须严格遵循本文档，禁止私自改动风格、尺寸、配色、布局结构。

**设计核心理念**：**极简国风 · 阅读优先 · 学术素雅 · 低干扰高沉浸**，摒弃冗余装饰，让古籍内容为核心，视觉服务阅读、交互服务效率。

## 1. 产品原型整体结构规范（全站统一布局原型）

全站所有页面遵循**固定三段式原型结构**，无特殊页面、无杂乱布局，保证用户认知统一、学习成本极低。

### 1.1 全局固定布局模型

- **顶部**：全局固定导航栏（常驻、不随页面切换消失），承载品牌、导航、搜索、功能开关（繁简切换、主题切换）
- **主体内容区**：承载页面核心内容，最大留白、阅读优先，自适应桌面/平板/手机
- **底部**：全局统一页脚，承载开源声明、合规公示、版权、项目说明、资源来源

### 1.2 全站页面原型清单（V1.0 全部页面）

1. 首页原型（门户聚合、馆藏入口、工具入口）
2. 馆藏分类列表页原型（十大馆藏分类聚合）
3. 书籍目录页原型（单书卷次/章节列表）
4. 古籍阅读页原型（核心阅读双语布局）
5. 检索结果页原型（结果列表、高亮、筛选）
6. 人物考据页原型（人物档案+史料聚合）
7. 社会关系溯源页原型（关系展示+双人查询）
8. 帮助与合规页原型（文档、声明、教程）

## 2. 全局UI设计系统

### 2.1 色彩系统（国风学术极简配色）

全站三套主题严格固定，**禁止自定义配色**。

#### ① 日间模式（默认）

- 页面背景：#F9F7F2（宣纸米白，国风基底）
- 正文文字：#2B2B2B（深墨黑，护眼不刺眼）
- 辅助文字：#666666（浅灰说明文字）
- 边框分割：#E8E4DD（浅宣纸分割线）
- 主色强调：#8C3130（暗朱红，国风点缀，用于按钮、高亮、选中态）
- 高亮检索：#F2D299（浅黄高亮，适配古籍阅读）

#### ② 护眼模式

- 页面背景：#F0F3E8（柔和护眼绿）
- 正文文字：#2C3324
- 辅助文字：#5A6152
- 边框分割：#D8DFCC
- 高亮检索：#D8D2A8

#### ③ 深色模式（夜间阅读）

- 页面背景：#1A1A1A
- 正文文字：#E5E5E5
- 辅助文字：#AAAAAA
- 边框分割：#333333
- 高亮检索：#B89A68（暗金高亮，适配深色）

### 2.2 字体系统（全站统一）

古籍平台**优先衬线字体**，贴合典籍阅读质感，中英文自动适配。

- 全局默认字体：**思源宋体、Noto Serif SC**（古籍阅读最优字体）
- 辅助UI字体：系统无衬线，保证按钮、导航、小字清晰
- 标题字号：20–24px，加粗、居中/左对齐克制展示
- 正文字号：16px（默认），支持14px/18px/20px无级调节
- 正文行高：1.8（古籍阅读黄金行高，舒展不拥挤）
- 段落间距：1rem，段落分明、排版规整

### 2.3 圆角、阴影、间距规范（统一克制）

- 全局圆角：6px（温和国风圆角，不尖锐、不圆润泛滥）
- 卡片阴影：低明度浅阴影，保证层次、不厚重
- 全局留白：左右自适应留白，桌面端最大容器宽度1200px，居中阅读区
- 组件间距：8px/16px/24px 三级固定间距，全站统一

## 3. 核心页面详细设计规范

### 3.1 首页

1. 顶部导航：Logo(古籍通) + 导航菜单 + 繁简切换 + 主题切换
2. 首页Banner区：极简文字Slogan、无大图、无花哨海报
3. 全局搜索框：居中大搜索框，支持标题检索/全文检索切换
4. 馆藏入口区：十大馆藏卡片均等排布，简洁素雅、hover微高亮
5. 学术工具入口：人物考据、社会关系溯源快捷入口
6. 底部公示区：开源协议、数据来源、免责、解压密码、网盘链接

### 3.2 分类/书籍列表页

- 面包屑导航：清晰层级回溯（首页 > 馆藏 > 书籍）
- 列表样式：纯文字极简列表，左对齐、hover高亮、无多余图标
- 分页/懒加载：平滑加载，无加载闪烁

### 3.3 古籍阅读页（全站最重要页面）

严格遵循**阅读沉浸优先**原则，零干扰设计

- 顶部章节标题居中展示，清晰区分卷次篇目
- 正文双语可控切换（繁体原版 / 简体对照）
- 正文段落规整排布、行高舒适、长文自动分页
- 上下章切换按钮固定悬浮/底部常驻
- 阅读设置面板：字号、行距、主题切换
- 划词检索、生僻字释义轻量化弹窗（不遮挡正文）

### 3.4 检索结果页

- 检索关键词置顶展示、命中数量统计
- 结果权重排序展示：标题优先、章节次之、正文最后
- 命中文字高亮、上下文片段预览
- 单条结果携带出处：馆藏-书籍-章节

### 3.5 考据功能页

- 人物基础信息卡片（结构化展示，整洁清晰）
- 宦历、生平、籍贯、朝代结构化分区
- 关联古籍文献列表聚合
- 社会关系分区展示、双人查询表单极简布局

## 4. 全局交互规范（全站统一）

- **无弹窗骚扰**：全站无广告、无启动弹窗、无推送弹窗
- **状态记忆**：主题、繁简模式、字号、行距、阅读进度本地永久记忆
- **hover交互**：所有可点击元素仅微变色、微提亮，无夸张动效
- **加载状态**：极简加载提示，无花哨loading动画
- **检索交互**：输入即检索、实时高亮、结果秒出
- **分片加载交互**：滚动预加载、无卡顿、无内容闪烁

## 5. 多终端适配规范

### 5.1 桌面端（≥1200px）

宽屏居中阅读容器，最大宽度1200px，左右留白舒适，卡片多列均分排布。

### 5.2 平板端（768px–1199px）

自适应缩减列数，保留完整功能，排版紧凑不拥挤。

### 5.3 移动端（≤767px）

- 导航转为折叠菜单
- 阅读页全屏沉浸，最大化正文展示区域
- 按钮、点击区域放大，适配触屏操作
- 排版单列自适应，杜绝挤压、错乱

## 6. 设计红线规范（禁止修改）

1. 禁止使用鲜艳、高饱和配色，破坏学术素雅调性
2. 禁止添加动效、动画、装饰元素，干扰阅读
3. 禁止随意更改字体、行高、留白，破坏古籍阅读质感
4. 禁止弹窗、浮窗、广告、会员、营销类UI元素
5. 禁止修改三套主题核心配色体系
6. 禁止破坏全站统一三段式原型布局结构
