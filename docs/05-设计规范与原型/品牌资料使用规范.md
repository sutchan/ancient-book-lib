# 古籍通 AncientBook｜品牌资料使用规范

**适用版本**：v1.2.3　**更新日期**：2026-09-08

统一品牌视觉资产（logo、图标、社交图）的来源、规格与使用场景，避免各处手写尺寸、重复切图。

## 1. 源图与单一来源

| 项 | 值 |
| --- | --- |
| 源图（原始） | `public/brand/logo-source.jpg`（2048×2048，米色纸底 + 朱红印章 + 黑色「古籍通 / AncientBook」） |
| 内容外接框 | x=392 y=784 w=1292 h=480（横版比例 **2.692 : 1**） |
| 印章方形区域 | x=392 y=776 size=488 |
| 品牌主色 | `#A93320`（印章朱红，采样自印章环形区域） |
| 纸色（背景） | `#F7F3EA`（用于实心图标底、maskable 底、OG 图底色） |
| 令牌文件 | `public/brand/brand-tokens.json`（主色 / 纸色 / 比例 / 源图路径） |

源图只允许替换 `public/brand/logo-source.jpg` 后重新生成，禁止手改生成产物。

## 2. 生成方式

依赖 Windows `.NET System.Drawing`（GDI+），无需安装任何 npm 包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/brand/build-brand-assets.ps1
```

脚本模块（均 < 200 行，按职责拆分）：

| 文件 | 职责 |
| --- | --- |
| `scripts/brand/build-brand-assets.ps1` | 编排：度量 → 抠底 → 各尺寸导出 → manifest / 令牌 → 复制到站点位 |
| `scripts/brand/brand-image.ps1` | 源图加载、内容度量、逐级缩放、纸底转透明、反白变体、PNG 保存 |
| `scripts/brand/brand-ico.ps1` | 多尺寸 ICO 封装（PNG 内嵌） |
| `scripts/brand/brand-social.ps1` | 1200×630 社交分享图绘制 |

处理要点：源图背景为米色纸底（亮度约 240–252），采用「亮度阈值 + 印章区域保护」抠底——印章内部白色线条亮度接近纸底，必须靠保护矩形保留，否则会被误抠。

## 3. 产物清单

### 3.1 `public/brand/`（资源库）

| 文件 | 规格 | 用途 |

| `logo-mark-solid-180.png` | 180×180，纸色实心底 | iOS「添加到主屏」图标 |
| `logo-mark-maskable-512.png` | 512×512，印章占 62%，纸色底 | Android maskable 图标（安全区） |
| `og-image.png` | 1200×630 | Open Graph / Twitter Card 分享图 |
| `brand-tokens.json` | — | 颜色与比例令牌 |
| `logo-source.jpg` | 2048×2048 | 源图副本（后续再生成的输入） |

### 3.2 站点接入位（由脚本自动复制，勿手改）

| 文件 | 来源 | 说明 |

## 4. 使用场景映射

| 场景 | 使用文件 |
| --- | --- |
| 导航栏（light / paper 主题） | `logo-full-512.png` |
| 导航栏（dark 主题） | `logo-full-light-512.png`（`components/Navbar.tsx` 按主题切换） |
| 浏览器标签图标 | `app/icon.png` + `public/favicon.ico` |
| iOS / Android 主屏 | `logo-mark-solid-180.png` / `logo-mark-maskable-512.png` |
| 微信 / 微博 / X 分享卡片 | `og-image.png` |
| README / 文档 / 原型 | `logo-full-512.png`（浅底）或 `-light-` 版（深底） |

## 5. 原型接入

原型自带品牌资源副本 `prototype/assets/brand/`（与 `public/brand/` 同源，重新生成后需同步复制）：

| 文件 | 说明 |
| --- | --- |
| `logo-mark-64.png` | 原型页面 favicon |
| `logo-mark-solid-180.png` | apple-touch-icon |
| `logo-full-light-512.png` | 深色主题反白 logo |
| `og-image.png` | 分享图预览 |
| `site.webmanifest` | 图标路径已改为 `./`（与 manifest 同目录） |

- 11 个原型页面（`prototype.html`、`wireframes.html`、`pages/*.html`）head 统一注入：icon / apple-touch-icon / manifest / `theme-color` / `og:image` / `twitter:card`，相对路径按目录层级取 `./` 或 `../`。
- 导航栏 logo 带 `data-logo-light`（原图）与 `data-logo-dark`（反白版）两个属性，`prototype/assets/prototype.js` 的 `syncBrandLogo()` 按主题切换，与线上 `components/Navbar.tsx` 行为一致。
- `wireframes.html`「六、品牌资料」章节展示横版 logo 双底色、图标尺寸梯度、色板、OG 图与规格表，作为设计与开发对齐基准。

## 6. 约束

- 生成产物（PNG / ICO / manifest / tokens）为脚本输出，**禁止手工编辑**；如需变更，改源图或脚本后重跑。
- 站点接入位的复制由脚本完成，避免手工复制造成版本漂移。
- 主色 `#A93320` 与 UI 主题色 `--color-primary: #8C3130` 为同色系但取值不同：UI 控件沿用 CSS 变量，品牌资产沿用令牌色，两者不互相覆盖。
- 生成脚本仅支持 Windows（依赖 GDI+）；其他平台请手工导出同规格文件并保持命名一致。
