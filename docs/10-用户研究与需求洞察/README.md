## 研究方法论

### 数据真实性原则

所有用户研究结论必须基于真实数据，禁止虚构：
- 用户画像：基于产品定位推导，标注为"假设"，需通过真实访谈验证
- 用户旅程：基于典型场景推导，需通过 GA4 行为数据验证
- 需求优先级：基于用户价值和实现成本评估，需通过用户反馈和使用率验证
- 可用性测试：必须招募真实用户执行，记录真实操作和反馈

### 研究循环

```
假设推导 → 文档输出 → 功能上线 → 数据收集 → 验证/修正 → 更新文档
    ↑                                                        ↓
    └────────────────── 持续迭代 ──────────────────────────┘
```

### 验证方法

1. **GA4 行为分析**：监控页面浏览、搜索→阅读转化率、停留时长、跳出率
2. **用户反馈入口**：通过页脚/阅读页收集真实用户反馈
3. **1v1 用户访谈**：每季度招募 3–5 位核心用户深度访谈
4. **可用性测试**：每重大版本执行 6 项核心任务测试
5. **A/B 测试**：对重要功能进行小范围定量验证
