# 古籍通 AncientBook｜资源分片请求规范

**文档版本**：V1.0 正式定稿
**适配代码版本**：v1.3.6　**最近校订**：2026-09-08

> **现状对齐（v1.3.6）**：实现见 `lib/remoteBook.ts` + `lib/fetchWithTimeout.ts`（`fetchRangeText`）——章节字节偏移来自构建期生成的 `public/index/chapters.json`，按章 Range 拉取；不支持分片的书目自动回退整本 fetch + IndexedDB 缓存（`lib/idb.ts`）。原文直链为上游 `raw.githubusercontent.com`，书目索引另有 jsDelivr / statically CDN 镜像降级（`lib/catalog.ts`）。

## 1. GitHub资源请求规则

- 禁止全量拉取大体积TXT文件（单文件数百MB）
- 统一使用 HTTP Range 字节分片请求
- 通过离线索引字节偏移精准定位片段
- 前端缓存已加载片段，避免重复请求

## 2. 分片加载流程

1. 用户打开章节 → 从索引读取该章节的 GitHub Raw 字节偏移量与片段范围
2. 前端发起 HTTP Range 请求，仅拉取当前章节片段
3. 渲染文本片段，不加载整本超大文件
4. 已读片段写入本地缓存，二次打开零请求

## 3. 限流规避规范

- 单页单次仅请求当前章节
- 预加载延迟节流，防止高频429限流
- 滚动预加载、无卡顿、无内容闪烁
- 已读内容本地缓存，大幅减少重复请求

## 4. 错误处理

- Range 请求失败时静默重试，最多重试2次
- 重试失败展示极简错误提示与刷新入口
- 不阻塞整页，保证阅读体验连续
