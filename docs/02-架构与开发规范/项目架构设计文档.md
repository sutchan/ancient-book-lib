# 古籍通 AncientBook｜项目架构设计文档

**文档版本**：V1.0 正式定稿（定稿不可变更）
**适配代码版本**：v1.3.7　**最近校订**：2026-09-08

## 1. 架构核心定位

采用 **GitHub原始资源 + 本地离线索引预处理 + Next.js SSG 静态构建 + 前端内存检索 + Range分片懒加载** 全链路纯静态架构。

**永久禁止**：数据库、动态服务渲染、线上实时解析大文件、全量拉取GitHub资源。

## 2. 整体链路流程

1. 本地克隆5GB古籍原始TXT资源
2. 离线语义分块、字节偏移记录、倒排索引构建、繁简映射固化
3. 生成轻量化静态索引池提交仓库
4. Next.js 全量SSG预渲染页面
5. 前端按需加载索引、内存检索、分片加载原文

## 3. 架构核心优势

- 无体积膨胀：原始5GB资源完全保真，仅新增轻量化索引（300–700MB）
- 无运维压力：纯静态文件，Vercel一键部署
- 无线上故障：无数据库OOM、超时、连接异常问题
- 高性能：检索速度20–80ms，碾压传统动态古籍网站

## 4. 三层架构分层

### 4.1 数据层（GitHub原始资源）

- 全量5GB古籍TXT托管于公开GitHub仓库
- 线上不存储、不入库、不复制原始大文件
- 仅通过离线索引字节定位 + Range分片请求按需调用

### 4.2 索引层（离线预构建静态索引池）

- 馆藏分级倒排索引：仅存词条、权重、位置、字节偏移、文件路径，不存原文
- 古籍专属繁简双向映射库：固化古字、异体字、避讳字、官职、年号、专有名词规则
- 索引按十大馆藏拆分，支持按需懒加载
- 总体积300–700MB，提交代码仓库，线上永久静态复用

### 4.3 展示层（Next.js SSG 静态站点）

- 全站SSG静态预渲染，无动态服务端渲染、无接口依赖
- 全文检索完全在前端内存执行
- 超大文本采用HTTP Range分片精准请求
- 前端本地缓存用户偏好、已读片段、检索记录

### 4.4 统计层（匿名访问分析，v1.0.2 起）

- 组件：`components/Analytics.tsx`（服务端组件，SSG 时直接写入初始 HTML）
- 方案：Google Analytics 4（衡量 ID `G-H76XG9L6FZ`），`next/script` afterInteractive 注入
- 范围：仅匿名聚合访问统计（页面浏览量、来源、设备），开启 IP 匿名化（`anonymize_ip`）
- 边界：不采集个人身份信息，不构成用户画像；用户屏蔽第三方 Cookie 即可停止
- 与架构一致性：统计代码随 SSG 静态产物输出，无服务端依赖，不破坏纯静态架构
