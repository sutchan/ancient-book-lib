# 古籍通 AncientBook｜项目目录结构规范

**文档版本**：V1.0 正式定稿

统一目录结构，规范化开发，禁止随意新建文件、文件夹。

```plain
ancient-book-lib/
├── docs/                # 全套项目规范、PRD、任务文档
├── public/              # 静态资源、图标、合规公示文件
│   └── index/           # 离线预构建静态索引资源（书目/全文/CBDB/章节，体积大已 gitignore）
├── app/                 # Next.js App Router 路由页面（SSG），根级目录（非 src/app）
│   ├── category/        # 馆藏分类页
│   ├── book/            # 书籍目录页
│   ├── book-list/       # 全馆藏列表页
│   ├── catalog/         # 书目检索入口页
│   ├── read/            # 阅读页（Range 分片按需加载原文）
│   ├── search/          # 检索结果页
│   ├── character/       # 人物考据引导页（已并入人物库，引导至 /people）
│   ├── people/          # 人物库（CBDB 全量检索）
│   ├── relation/        # 社会关系页
│   ├── stats/           # 数据统计页
│   ├── help/            # 帮助合规页
│   ├── data-source/     # 数据来源页
│   ├── license/         # 许可协议页
│   ├── feedback/        # 反馈页
│   ├── disclaimer/      # 免责声明页
│   ├── layout.tsx       # 全局布局（含 GA4 埋点、字体）
│   ├── page.tsx         # 首页
│   ├── globals.css      # 全局样式（原生 CSS，无 Tailwind）
│   ├── not-found.tsx    # 404 页
│   └── robots.ts        # robots 配置
├── components/          # 全局公共组件（Navbar、Footer、Analytics、ReaderToolbar 等）
├── lib/                 # 工具函数、检索、分片请求、CBDB/章节解析
├── scripts/             # 离线预处理脚本（分块、索引构建、品牌资源生成）
├── prototype/           # 高保真可交互原型（prototype.html、pages/、assets/、data/）
├── .gitignore
├── next.config.mjs
├── package.json
└── CHANGELOG.md
```

## 目录职责说明

- **docs/**：项目全套官方文档，统一归档，跟随Git版本同步管理
- **prototype/**：高保真可交互原型目录，含入口原型、组件库规范、独立页面原型、真实模拟数据、三套主题
- **public/index/**：离线预构建静态索引资源（书目/全文/CBDB/章节索引，体积大已 gitignore，部署期生成）
- **scripts/**：离线预处理脚本（文本分块、索引构建、繁简映射生成）；`scripts/brand/` 为品牌资源生成脚本（logo / 图标 / 分享图，Windows GDI+）
- **public/**：静态资源、图标、合规公示文件；`public/brand/` 为品牌资料资源库（脚本生成，禁止手改），详见 `docs/05-设计规范与原型/品牌资料使用规范.md`

## 命名规范

- 文件夹、文件：小写短横线命名（kebab-case）
- 组件文件：大驼峰命名（PascalCase）
- 索引文件：按馆藏分类命名（如 ru.json、yi.json、shi.json）
