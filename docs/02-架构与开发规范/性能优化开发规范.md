# 古籍通 AncientBook｜性能优化开发规范

**文档版本**：V1.0 正式定稿
**适配代码版本**：v1.3.6　**最近校订**：2026-09-08

> **现状对齐（v1.3.6）**：检索为「标题检索（始终可用，基于 5.7MB 目录索引）+ 全文检索（需 `npm run build:fulltext` 生成倒排索引，缺失时自动回退标题检索）」，见 `lib/search.ts`。大文本按章 Range 拉取（`chapters.json` + `lib/remoteBook.ts`），不做整本加载。CI（`.github/workflows/deploy.yml`）已强制跑 `build:catalog` → `build:fulltext` → `next build` → `npm test`。

## 1. 核心性能指标（强制验收标准）

- 页面首屏加载 ≤ 1s，无白屏、无卡顿、无闪烁
- 前端检索响应速度 20–80ms，秒级出结果、无等待
- 超大文本分片加载无超时、无截断、无内存溢出
- 索引按需懒加载，低配手机、老旧设备可流畅访问

## 2. 性能优化强制规范

- 全站SSG预构建，静态页面零动态渲染
- 索引分片懒加载，不一次性加载全量索引
- 资源静态缓存、浏览器缓存策略最优配置
- 检索算法轻量化，保证低配设备流畅运行
- 图片、静态资源极致压缩
- 大文件、图谱资源懒加载 + CDN全局缓存

## 3. 检索性能优化

- 检索完全在前端内存执行，不请求后端
- 索引按馆藏分类拆分，用户检索时仅加载对应分类索引
- 权重排序规则静态固化：标题完全匹配 > 章节名匹配 > 段落开头匹配 > 正文高词频匹配 > 普通正文匹配

## 4. 加载策略

- 目录列表 SSG 静态预渲染
- 章节内容懒加载 + 分片加载
- 检索结果索引匹配 + 片段预览
- 阅读进度、偏好本地缓存，二次访问极速加载
