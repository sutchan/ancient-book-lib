# 古籍通 AncientBook｜代码开发规范

**文档版本**：V1.0 正式定稿

## 1. 技术栈固定

Next.js 14、TailwindCSS、原生TypeScript、前端轻量检索引擎，禁止引入冗余重型依赖。

## 2. 命名规范

- 文件夹、文件：小写短横线命名（kebab-case）
- 组件：大驼峰命名（PascalCase）
- 变量、函数：小驼峰命名（camelCase）
- 常量：全大写下划线命名（UPPER_SNAKE_CASE）

## 3. 开发强制约束

- 所有页面必须 SSG 静态预渲染，禁止动态SSR
- 所有检索逻辑运行在前端，禁止后端接口检索
- 所有大文件读取必须走 Range 分片请求
- 禁止线上直接读取超大原始文件
- 用户配置全部本地缓存，禁止服务端存储
- 禁止引入数据库依赖（MySQL、SQLite、MongoDB等全部禁止）
- 颜色全部使用CSS变量，禁止写死色值

## 4. 组件开发规范

- 所有组件优先复用全局组件库，禁止重复写独立样式
- hover、active、disabled 状态必须完整实现
- 移动端所有组件点击区域 ≥ 44px
- 三套主题（日间/护眼/深色）下组件表现必须全部兼容

## 5. 代码质量要求

- 组件、工具函数必须有清晰注释
- 检索、分片请求等核心逻辑必须单元测试覆盖
- 禁止遗留 console.log 调试代码
- 代码提交前必须通过 lint 与类型检查
