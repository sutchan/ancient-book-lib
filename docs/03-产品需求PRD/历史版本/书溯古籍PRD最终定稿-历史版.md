# 书溯古籍（BookScribe）开源古籍文献平台 PRD 最终定稿（历史版本·已被古籍通替代）

> **归档说明**：本版本为品牌定名「古籍通 AncientBook」之前的旧版PRD，已被 `03-产品需求PRD/V1.0上线版产品需求文档.md` 完全替代。保留仅供历史追溯，不再作为开发依据。

**版本号**：V1.0 Final（技术架构定稿）

**核心架构**：彻底移除所有数据库依赖，全线采用「GitHub源文件托管 + 本地离线索引预构建 + 前端内存检索 + 分片懒加载」纯静态架构，适配5GB超大古籍TXT资源。

## 1. 项目概述

### 1.1 项目背景

项目依托开源殆知阁十大藏库古籍资源（总体量5GB纯TXT文本），同时对标CBDB历代人物传记数据库学术能力，解决传统古籍查阅工具检索繁琐、加载卡顿、无章节拆分、无双语阅读、无学术考据能力、下载混乱等痛点。

### 1.2 产品定位（双轨精准定位）

**基础定位**：零广告、零注册、零付费的开源古籍普惠阅读工具，实现十大藏库古籍结构化浏览、繁简双语切换、极速检索、一键下载。

**进阶定位**：轻量化人文考据学术工具，融合古籍全文检索与历代人物、社会关系、宦历谱系溯源能力。

### 1.3 核心目标

- 架构轻量化：彻底舍弃数据库，规避5GB文本入库体积膨胀、部署超时、OOM崩溃问题
- 检索极速化：基于预构建静态索引，实现前端毫秒级全文检索
- 阅读专业化：上线古籍级繁简双语保真切换、章节分片阅读、阅读进度记忆、生僻字释义
- 学术工具化：落地CBDB同款人物档案、社会关系、双人溯源、朝代考据能力
- 体验普惠化：全终端适配、无门槛使用、统一资源下载渠道、稳定无限流

## 2. 核心功能模块

- 首页模块：全局固定导航、核心搜索框、馆藏分类卡片、学术工具快捷入口、底部公示
- 三级结构化分类浏览：一级十大馆藏分类；二级单本古籍书目；三级拆章节目录
- 双模式极速检索：基础检索（标题/全文）+ 高级多维学术检索（朝代/地域/人物/馆藏/文体）
- 古籍级繁简双语阅读：繁体100%还原原始文本，简体专属古字映射
- 分片懒加载阅读机制：索引字节定位+Range分片请求
- 人物考据与社会关系模块：人物档案、文献关联、关系溯源、双人查询、重名区分
- 资源下载模块：单章节/单本/整库下载，统一解压密码公示，限流提示
- 帮助与共建模块：使用教程、志愿者共建、反馈渠道、数据合规声明

## 3. 技术架构

**GitHub原始5GB TXT资源 + 本地离线预处理 + 静态索引池 + 前端内存检索 + 远程分片懒加载**

- 技术栈：Next.js14+（SSG全静态生成）、TailwindCSS、前端轻量检索引擎
- 离线预处理：文本分块（单块2-4KB）、静态倒排索引、索引分类拆分、繁简双向预映射
- 线上运行：页面SSG预渲染、前端内存检索、Range分片请求、本地缓存

## 4. 路由规划

- / 首页
- /category/[type] 馆藏分类列表
- /book/[id] 书籍详情与章节目录
- /read/[chapterId] 章节双语阅读页
- /search 检索结果页
- /character 人物考据主页
- /relation 社会关系溯源页
- /help 使用教程与开源合规说明

## 5. 版本迭代规划

- V1.0 基础稳定版：纯静态架构落地、无数据库、全馆藏浏览、繁简双语保真切换、基础检索、分片阅读、统一下载、全终端适配、合规声明完整
- V1.1 体验优化版：阅读样式自定义、阅读进度记忆、生僻字释义、检索历史、索引优化提速
- V1.2 学术完整版：完整人物档案、关系图谱可视化、双人溯源、朝代筛选、史料出处标注

## 6. 项目约束与硬性技术规范

1. 永久舍弃数据库架构
2. 源文件零修改规范
3. 索引离线预构建规范
4. GitHub访问规范：禁止线上全量拉取，仅分片Range按需请求
5. 学术数据规范：仅采用公开权威数据源
6. 非商用合规规范：平台永久公益开源
