# 古籍通 AncientBook｜项目 README 开源说明文档

**项目名称**：古籍通 / AncientBook
**工程仓库名**：ancient-book-lib
**文档版本**：V1.0 正式定稿

## 1. 项目简介

**古籍通（AncientBook）** 是一款**零数据库、纯静态、公益开源**的古籍文献检索与阅读平台。依托殆知阁5GB全量开源古籍资源，实现十大馆藏古籍结构化浏览、毫秒级全文检索、古籍级繁简双语保真阅读、超大文本分片懒加载、历史人物与社会关系考据能力。

项目基于 Next.js 14 SSG 全静态架构开发，无后端服务、无数据库、零运维、零膨胀、永久稳定，面向学生、国学爱好者、文史研究者、内容创作者提供普惠、纯净、专业的古籍数字化服务。

## 2. 核心特性

- **纯静态架构**：彻底舍弃数据库，全网唯一超大古籍静态最优方案
- **毫秒级检索**：前端内存检索，20–80ms 极速响应
- **保真双语阅读**：古籍专属繁简映射，杜绝通用转换失真
- **超大文件适配**：HTTP Range 分片懒加载，解决数百MB文本加载难题
- **学术考据能力**：对标CBDB，支持人物档案、社会关系、史料溯源
- **全终端适配**：手机/平板/桌面端自适应，流畅访问
- **纯净公益**：无广告、无注册、无付费、无隐私收集

## 3. 资源覆盖

佛藏、儒藏、医藏、史藏、子藏、易藏、艺藏、诗藏、道藏、集藏 十大完整古籍馆藏。

## 4. 快速部署

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 静态构建
npm run build

# 启动静态预览
npm run start
```
