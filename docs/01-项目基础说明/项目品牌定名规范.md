# 项目品牌名称最终定稿｜古籍通 AncientBook

**定稿状态**：正式锁定，全项目统一启用，替代原有所有旧品牌名称

**适用范围**：PRD文档、项目工程、GitHub仓库、网站标题、SEO配置、开源公示、线上备案、宣传物料

## 一、最终定稿全套品牌信息

- **中文正式名称**：古籍通
- **英文品牌名称**：AncientBook
- **GitHub 仓库工程名**：ancient-book-lib
- **产品全称（官方标准）**：古籍通 AncientBook 开源古籍文献检索阅读平台

## 二、品牌释义（官方定稿）

「古籍通」寓意古籍一键通达、全库贯通、随查随读。名称直白易懂、零认知门槛，用户可直观识别产品核心能力为**古籍在线阅读、全文检索、文献查阅、典籍研读**。名称无晦涩字义、无歧义，同时保留正统国风质感，兼顾大众普惠与学术专业场景，适配公益开源产品定位。

## 三、核心品牌优势

- **极简易记**：三字短名，记忆成本极低，传播性强，老少皆宜；
- **功能直白**：看名知用途，精准匹配古籍阅读、检索、查文献核心需求；
- **SEO高度适配**：贴合大众主流搜索词，自然曝光优势显著；
- **全场景兼容**：同时适配学生学习、爱好者研读、学术考据、素材复用；
- **开源规范**：英文名称简洁标准，仓库命名合规，适配工程部署与社区共建。

## 四、全站统一落地规范（强制执行）

- **工程目录/资源命名**：统一使用 ancient-book-lib

- **产品整体调性**：公益纯净、极简工具、普惠国学、专业可考
