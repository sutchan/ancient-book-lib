# 古籍通 AncientBook｜项目整体概述

**文档版本**：V1.0 正式定稿
**工程仓库名**：ancient-book-lib

## 1. 项目定位

**古籍通（AncientBook）** 是一款**零数据库、纯静态、公益开源**的古籍文献检索与阅读平台，定位为「大众普惠阅读 + 专业学术考据」双轨一体的开源古籍数字化工具。

- **基础普惠定位**：零广告、零注册、零付费、不收集个人隐私的纯公益开源古籍工具（仅匿名访问统计，GA4），面向学生、国学爱好者、传统文化学习者，提供结构化浏览、毫秒级检索、保真双语阅读、规范化资源下载。
- **专业学术定位**：轻量化人文考据研究工具，对标哈佛CBDB、中研院史学数据库学术能力，打通古籍全文资源与历代人物、官职宦历、社会关系、朝代史料的联动溯源。

## 2. 项目背景与行业痛点

本项目依托殆知阁开源十大藏库资源，整合总计5GB高纯无噪纯TXT古籍文本，是国内公开可获取的完整性、保真度、权威性顶尖的开源古籍文库。原始资源托管于GitHub，存在检索低效、超大文件无法完整加载、无章节结构化拆分、无繁简保真对照、无学术考据联动、下载体系混乱、移动端体验缺失等原生短板。

市面现有古籍平台普遍存在能力割裂问题：大众阅读平台仅有原文浏览、无学术考据与文本深加工能力；人文学术数据库（CBDB等）仅有人物史料数据、无完整古籍原文阅读与典籍溯源能力，形成「阅读无考据、考据无原文」的行业痛点。

## 3. 核心架构理念

基于 Next.js 14 全静态 SSG 架构重构，**永久舍弃传统数据库存储方案**，采用「本地离线索引预构建 + 前端内存检索 + 远程分片懒加载」创新架构，彻底解决超大文本入库膨胀、部署崩溃、检索超时等问题，在完全保留古籍原文保真、不膨胀资源体积、零运维成本的前提下，构建完整产品闭环。

## 4. 核心目标

- 彻底解决5GB超大TXT古籍加载、检索、阅读、复用、下载全流程痛点
- 搭建古籍专属繁简双语体系，解决通用转换工具古字、异体字、专有名词失真丢失问题
- 落地轻量化、高稳定、可复用的前端内存全文检索体系，实现毫秒级检索响应
- 打通古籍文献与历史人物、社会关系、朝代史料的联动考据能力
- 实现全终端适配、零门槛使用、合规可备案、可长期迭代、可社区共建的产品形态

## 5. 资源托管规范

- 全量5GB古籍TXT源文件永久托管于公开GitHub开源仓库，溯源清晰、公开可查、合规可复用
- 线上生产环境**不存储、不入库、不复制、不篡改原始大文件**，100%保留原版古籍文本保真度
- 所有原文在线调用统一采用「离线索引字节定位 + 远程Range分片懒加载」模式
- 馆藏分类全覆盖：佛藏、儒藏、医藏、史藏、子藏、易藏、艺藏、诗藏、道藏、集藏十大正统古籍文库

## 6. 核心差异化优势

- 国内首个集齐「完整十大藏库开源古籍 + 古籍级繁简保真双语体系 + 人物社会关系学术考据 + 全维度文本深加工」的纯静态开源平台
- 独创无数据库超大文本解决方案，5GB资源零体积膨胀、零部署风险、零运维成本
- 纯公益无商业化套路，无用户隐私采集、无广告推送、无付费壁垒
- 兼顾大众轻量化阅读与专业学术考据，填补「阅读与考据割裂、普及与研究分离」行业空白
