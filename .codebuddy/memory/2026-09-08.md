## 从 CBDB 导入人物考据数据（v1.3.8）
- 用户指定数据源 CBDB（站点 cbdb.hsites.harvard.edu，实际 REST API 在 `cbdb.fas.harvard.edu/cbdbapi/person`，授权 CC BY-NC-SA 4.0）。新增 `scripts/build-characters.mjs`：以**已校验 CBDB 人物 ID** 为种子，按 `?id=` 拉取，对返回 PersonId 二次核验；从 `PersonTexts`（角色含 撰/著/編/輯/注/箋/疏/述）提取著述作为 `books`；生成 `public/index/characters.json`（28 位历史名人：孔子/老子/李白/杜甫/蘇軾/朱熹/司馬遷/王維/曹雪芹等）。
- **关键坑：CBDB `?name=` 检索非确定性且常命中同名 obscure 人物**（实测 `?name=司馬遷`→蘇振文/错误 ID、`?name=孔子`→孔子仲、`?name=老子`→范仲淹），`?id=` 才稳定可靠。故导入一律用 ID，且种子 ID 须来自权威来源（本次经 ctext 的 `authority-cbdb` 与 CBDB `person.php` 链接校验）。已校验 ID：司馬遷 439127、王維 32174、老子/李耳 339621、李白 32540、杜甫 3915、蘇軾 3767、朱熹 3257、白居易 32227。
- CBDB 个别记录朝代缺失/误标（司馬遷 Dynasty 空、老子误标唐），在种子中以 `dynasty` 覆盖为西漢/春秋。少数人物（杜甫/曹操/羅貫中/曹雪芹等）CBDB 未标「撰著者」故 books=0，属真实数据缺漏，页面如实显示「相关典籍 (0)」。
- 版本 bump 1.3.7→1.3.8，新增 `build:characters` npm 脚本。5 个相关文件（characters.json / build-characters.mjs / package.json / CHANGELOG.md / README.md）已 `git add` 暂存，未提交，待用户确认。
