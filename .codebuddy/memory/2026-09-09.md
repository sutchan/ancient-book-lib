## CBDB 帮助文件（xyinde cloud）研读（2026-09-09）
- 用户要求阅读 `https://api.cloud.xyinde.com/cbdb/v3/basicSearch/getHelpFile`。该 URL 返回的是 **《CBDB 在线使用手册》PDF**（引得数字人文平台，运营方北京元引科技 www.inindex.com，2023.9），是**产品使用手册而非 REST 接口规范**。用 pdfjs-dist（--no-save 安装，CMaps 解码中文）成功提取 77 页正文。
- 手册揭示 CBDB 数据模型与 10 类查询（人名/地名/职官/入仕/亲属关系/社会关系/社会关系网络/两人社会关系/社会区分/可视化），与 `scripts/build-characters.mjs` 已从 Harvard `cbdbapi` 提取的字段（BasicInfo 生卒/朝代/别名、PersonAddresses 籍貫、PersonPostings 官职、PersonTexts 著述）完全吻合。
- 关键缺口：`relations.json` 仍为空 `[]`，无 `build-relations.mjs`；`RelationClient` 预期 `Relation{a,b,type,source,detail,dynasty}[]`。CBDB 手册确认含亲属关系（五服：父/母/兄/弟/子/女…）与社会关系（5 大类/400+ 类别：学术/朋友/政治/著述等），正是该字段的数据源。
- 诚实局限：该 PDF 不含 v3 REST 端点具体路径/参数/鉴权/JSON schema（仅 `basicSearch` 路径前缀暗示端点分组）；本项目现用 Harvard `cbdbapi` 而非 xyinde v3。要接入关系数据，可在现有 Harvard API（`PersonKin`/`PersonAssoc`）基础上扩展脚本，无需依赖 v3 spec。
- 清理：解析用的 `.tmp/` 与 `node_modules/pdfjs-dist`（--no-save，未写入 package.json，node_modules 已 gitignore）已处理，未污染仓库。
