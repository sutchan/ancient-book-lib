# 2026-09-12

## 修复：CBDB 人物库姓氏分片 404（v1.4.6）
- 症状：人物库大姓详情/列表报错 `Error: 姓氏分片加载失败: 404`（仅 top200 大姓 standalone 分片，小姓走 `_others.json` 不受影响）。
- 根因（文件名双重编码）：`scripts/build-cbdb-index.mjs` 用 `encodeURIComponent(surname)` 作为**磁盘文件名**（字面量 `%E6%9D%8E.json`），而 `lib/cbdb.ts:101` 又请求同一编码路径；静态服务器把 `%E6%9D%8E` 解码成「李」后，磁盘无「李.json」、只有「%E6%9D%8E.json」→ 404。
- 修复：将 `public/index/cbdb/surnames/` 下 480 个 `%XX.json` 还原为真实中文名（`李.json` 等）；构建脚本改为写真实中文文件名、meta 仍存 URL 安全路径（编码），保持一致。其它 cbdb 子目录（entry/offices/rel/sources/altnames/geo）用数字/ASCII 分片名，无此问题。
- 验证：`scripts/_verify_surname.mjs` 校验 200 个 standalone 分片全部命中；tsc 此前已通过。
- 版本：package.json 1.4.5→1.4.6，CHANGELOG 新增 `[1.4.6]`；改动已 `git add` 暂存（480 重命名 + package.json + CHANGELOG），未提交。
