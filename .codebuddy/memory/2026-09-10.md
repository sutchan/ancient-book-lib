## 发现：既有 P0-3 失败（简体搜繁体书目），属第二批 #3
- `npm test`：30 tests / 29 pass / **1 fail**（非本轮引入，P0-3 在本轮新增用例之前执行）。
- 现象：`searchByTitle("苏轼", …)` 打不中繁体书目「蘇軾文集」→ 返回 0；繁体「蘇軾」反而命中。
- 根因：`lib/catalog.ts` `searchCatalog` 归一化分支带守卫 `(qNorm !== q && norm.get(b.id).includes(qNorm))`。简体查询时 `toSimplified(q) === q` → 守卫为假 → 归一化匹配被跳过，只剩原文子串匹配。
- 修复方向：去掉 `qNorm !== q` 守卫，始终额外尝试归一化 haystack 匹配（haystack = `toSimplified(标题+馆藏+子类)`）。即第二批 #3「简繁归一化统一」，用户已排期，本轮未动。
